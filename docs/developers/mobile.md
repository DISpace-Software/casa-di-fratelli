# Мобильное приложение: разработка

Откройте `workspaces/mobile.code-workspace` и следуйте [установке Flutter и настройке режимов](../../mobile/README.md). Для визуальных тестов выберите описанный там offline demo; стандартный запуск может обращаться к production API.

```sh
cd mobile
flutter pub get
flutter analyze
flutter test
```

Меняйте код в `mobile/lib`, проверяйте сценарий на нужном устройстве/эмуляторе. Для live-тестов выбирайте изолированный API явно через `SEATMAP_API_BASE_URL`.

Создайте PR по [общему процессу](../../CONTRIBUTING.md), приложите результаты Flutter-проверок: текущие обязательные web/backend jobs не заменяют мобильные тесты. После merge требуется отдельная сборка и распространение приложения. Подпись и установка iPhone описаны в [инструкции](../../mobile/docs/IPHONE_TESTING.md); merge не обновляет установленное приложение автоматически.
