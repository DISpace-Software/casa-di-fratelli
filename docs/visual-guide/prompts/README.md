Изображения — обзорная форма документации. Точные статусы, версия среза, ограничения и редактируемые Mermaid-схемы находятся на соответствующих страницах [путеводителя](../README.md). Промпт отражает задание генератору; источником истины о проекте остаются проверенные исходники и настройки, перечисленные в [evidence.json](../evidence.json).
