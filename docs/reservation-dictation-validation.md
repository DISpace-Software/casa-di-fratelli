на диск. Отмена HTTP не освобождает слот, пока native inference действительно не
закончится. CPU/GPU Docker recipes подготовлены, но **Docker и NVIDIA GPU не
запускались**: локальный Docker daemon недоступен, GPU хоста нет.

Дополнительно проверена фактическая конфигурация Render: live API — Starter,
0,5 CPU / 512 MB, Ohio. Подготовлены отдельные `speech-service/render.yaml` и
`Dockerfile.render` с закреплённой моделью. Удалённая проверка Blueprint возвращает
одну ошибку: локальная feature-ветка ещё не опубликована на GitHub. Размещения и
замера на Render не было; детали в [плане Render](reservation-dictation-render.md).

## Настоящее распознавание звука

Использованы синтетические болгарские WAV, созданные голосом macOS Daria. Живой
микрофон администратора не записывался. Это небольшая диагностическая выборка из
шести полей, а не статистическая оценка качества речи в ресторане.

Chrome на macOS распознал все шесть файлов через настоящий SpeechRecognition.
Это не доказывает поддержку болгарского в Chrome на iPad; production использует
собственный worker и не полагается на этот результат.

Собственные модели сравнивались на x86_64 Mac, CPU, int8, четыре потока:

| Вариант | Время обработки короткого файла | Наблюдение |
| --- | --- | --- |
| Whisper small, beam 3 | 1,5–2,9 с | Ошибки в цифрах телефона, времени и гостях |
| small с подсказкой поля | 1,8–2,3 с | Ошибки не исправились; готовые ответы в prompt не подмешивались |
| medium | 7,6–12,1 с | Имя/телефон правильные, ошибки даты/времени/гостей/email |
| large-v3-turbo, beam 3 | 11,2–21,7 с | Пять основных полей правильные; email требует обработки spoken marker |

Затем проверена полная цепочка **браузер → реальный .NET API → настоящий worker
Whisper → парсер → реальные поля формы**. Подменялся только захват микрофона:
MediaRecorder выдавал заранее подготовленный WAV. Авторизация, upload, inference
и обновление формы были настоящими, локальными.

- Turbo, beam 5: имя, телефон, дата, время и гости заполнены верно; 9,0–14,9 с.
  Email не уложился в клиентский лимит; поле сохранилось пустым.
- После настройки beam 1 отдельный настоящий API-запрос email завершился за
  8,1 с: `georgi.ivanov.maimunka.gmail.com`. Парсер теперь поддерживает точный
  болгарский spoken marker `maimunka`, не меняя адреса с существующим `@` и не
  угадывая транслитерацию.
- Повторный полный прогон beam 1: пять основных полей заполнены верно,
  8,4–18,6 с. Email снова достиг лимита и не заполнился. **Release gate не пройден**.
  Тестовый скрипт ждал сетевой ответ до 30 с; UI завершает обработку по собственному
  20-секундному лимиту. Эти 30 с не являются временем успешного inference.

Увеличивать тайм-аут вместо выполнения требования скорости не стали. Модель
`small` оставлена только как исходный CPU baseline в конфигурации worker — её
нельзя считать проверенным вариантом для боевой болгарской диктовки. Выбор модели,
beam и вычислительного сервера требует повторного измерения на целевом хосте.

## Воспроизводимость

```sh
npm --prefix frontend test
node scripts/check-bulgarian-voice-corpus.mjs /path/to/evidence/corpus
dotnet build backend/SeatMap.SpeechChecks -p:UseAppHost=false
dotnet backend/SeatMap.SpeechChecks/bin/Debug/net8.0/SeatMap.SpeechChecks.dll
python -m pytest -q speech-service/tests
```

Browser scripts принимают приватный state disposable fixture, папку результата,
путь к Playwright и Chrome. `check-reservation-audio-browser.mjs` дополнительно
принимает путь к WebKit; `check-reservation-selfhosted-browser.mjs` — папку с WAV.
Последний скрипт обращается к реальному локальному worker и завершается ошибкой,
если хотя бы одно из шести полей не заполнено правильно. Все скрипты запрещают
production origin и изменения операционных данных.

Локальные отчёты и скриншоты находятся в исходном workspace:
`output/casa-production-voice-20261117/` (не коммитятся). Ключевые подкаталоги:
`browser-native`, `browser-audio`, `browser-real-worker`,
`browser-real-worker-beam1`, `actual-asr`, `corpus`. Приватные сессии и service
token хранятся отдельно во временных файлах с правами 0600 и в Git не добавлялись.

Turbo weights: `mobiuslabsgmbh/faster-whisper-large-v3-turbo`, snapshot
`0a363e9161cbc7ed1431c9597a8ceaf0c4f78fcf`; runtime versions закреплены в
`speech-service/requirements.txt`.
