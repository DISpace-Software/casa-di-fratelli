## Воспроизведение

Из worktree, с Node 22 и .NET 8 в PATH:

```sh
npm --prefix frontend test
node --test frontend/src/cofein/bookingApi.test.js
npm --prefix frontend run lint
npm --prefix frontend run build:cofein
npm --prefix frontend run build:admin
dotnet run --project backend/CasaDiFratelli.ReservationChecks
```

Для отдельной базы используйте `scripts/check-shared-admin-local.py --help`. Скрипт требует fixtures-root с исходным Cofein JSON и меню; они сохранены в исходной рабочей папке. Браузерные сценарии принимают путь к приватному состоянию этого локального стенда, каталог результатов, модуль Playwright и Chromium. Перед записью проверяют признак `localOnly` и адрес localhost.
