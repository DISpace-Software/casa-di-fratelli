# Исправление телефона и повторной подготовки диктовки

18 ноября 2026 в общей админке опубликован frontend `85d78c0`.
Vercel: `dpl_FhiJQxQqjbjnRrWgyL1td2YegeyM`, production READY.
Рабочий адрес: `https://seatmap-admin-eight.vercel.app`.
Одна сборка обслуживает Casa, Cofein и остальные restaurant routes.
Backend остаётся на `af01a5a`; политика API и данные ресторанов не менялись.

## Изменения

- Убран большой блок «Подготви диктовката…». Модель автоматически готовится
  при открытии формы, без запроса микрофона; остаётся краткий статус загрузки.
  В готовой форме видны только микрофоны имени и телефона.
- Телефон записывается до нажатия «Стоп» или 20-секундного предела.
  Паузы между цифрами больше не обрывают запись.
- AudioWorklet сохраняет PCM/WAV без AAC-сжатия. В прежнем пути реальный
  WebKit/AAC ухудшал конкретную тестовую фразу; тесты с подставленным готовым
  WAV не обнаруживали этот дефект. При недоступности AudioWorklet сохраняется
  MediaRecorder fallback до начала записи.
- Неполные распознанные цифры появляются в редактируемом черновике. Основной
  телефон меняется только после подтверждения валидного номера; недостающие
  цифры не угадываются.
- Ошибка декодирования или отмена до инференса больше не уничтожает исправную
  модель. CacheStorage заполняется порциями из загруженных данных без
  `Response.clone()`; закреплённые файлы имеют immutable HTTP-кэширование.

Звук обрабатывается в памяти устройства. Новые платные ресурсы, внешний ASR,
серверная передача аудио и дополнительные разрешения на хранение не добавлены.

## Проверка опубликованной формы

На реальном Cofein Basic прошли **4/4** пробы: имя и телефон в карте, затем
оба поля в списке. Настоящие AudioWorklet, PCM/WAV, декодер, Worker и модель;
только источник звука — синтетический MediaStream. Созданы четыре PCM worklet,
MediaRecorder fallback не использовался. Первичная подготовка заняла 10,245 с,
распознавание после остановки — 0,206–0,841 с на проверенном Mac/Chrome.
Между формами повторных запросов модели не было.

Телефон до подтверждения оставался прежним; ручные поля не менялись. Разрешён
единственный POST входа. Сохранений броней, других операционных записей,
запросов voice API, внешнего runtime и ошибок JavaScript не было.
Отчёт: `output/dictation-repeat-fix-20261118/production-real-pcm/report.json`.
Скриншоты содержат только несохранённую тестовую форму.
